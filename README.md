# Canvas Game

Простая игра на HTML5 Canvas. Управляйте синим квадратом с помощью стрелок, собирайте монетки и сражайтесь с врагами.

## Как играть

- **↑ ↓ ← →** — движение персонажа
- **Пробел** — выстрел в направлении движения
- **Enter** — начать игру / пропустить заставку уровня
- **R** — начать заново (после проигрыша или победы)

Перед началом игры показывается экран с объяснением управления.

### Цель

Соберите нужное количество монет на уровне, чтобы перейти дальше. В конце вас ждёт финальный босс.

- Каждая монета и побеждённый враг дают **1 очко** (босс — **20 очков**)
- У игрока **3 жизни (♥)**, при касании врага теряется 1 жизнь
- После потери жизни игрок становится неуязвимым на короткое время

## Уровни

| # | Локация    | Описание                                     |
|---|------------|----------------------------------------------|
| 1 | Лес        | Зелёные деревья, простые враги               |
| 2 | Пустыня    | Кактусы, враги быстрее                       |
| 3 | Снега      | Снеговики, враги живучее (2 HP)              |
| 4 | Вулкан     | Горящие камни, быстрые враги                 |
| 5 | Космос     | Астероиды и **финальный босс**               |

В каждой локации есть препятствия, которые блокируют движение и пули.

## Запуск

Откройте `index.html` в браузере.

## Технологии

- HTML5 Canvas
- JavaScript (без внешних библиотек)
- Web Audio API для звуков
