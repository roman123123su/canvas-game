# Canvas Game

Простая игра на HTML5 Canvas. Управляйте синим квадратом с помощью стрелок на клавиатуре и собирайте красные монетки.

## Как играть

- **Стрелки (↑ ↓ ← →)** — движение персонажа
- Каждая собранная монетка даёт **1 очко**
- При сборе монетки воспроизводится звук
- После **30 очков** счёт сбрасывается в 0

## Запуск

Откройте `index.html` в браузере.

## Технологии

- HTML5 Canvas
- JavaScript (без внешних библиотек)
- Web Audio API для звуков
